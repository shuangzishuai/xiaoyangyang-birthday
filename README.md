# 小羊羊的生日惊喜页面

一个本地网页：打开后有开场动画、轻快版《生日快乐》（网页实时合成，不需要音频文件）、
吹蜡烛互动、合照占位相框和一封情书。手机、电脑都能看。

## 怎么打开

1. 推荐方式：双击 `打开生日惊喜.command`，会自动启动本地助手并打开页面。
2. 备选方式：直接双击 `index.html` 也能看（开机开关功能需要助手在运行）。

## 换照片

把你们的合照命名为 `photo1.jpg`、`photo2.jpg`、`photo3.jpg` 放进 `photos` 文件夹，
刷新页面就会自动替换卡通占位图（也支持 `.jpeg` / `.png` / `.webp`）。

## 开机自动打开开关

1. 电脑上先双击一次 `打开生日惊喜.command`（启动本地助手）。
2. 打开页面后，点左下角齿轮打开「设置」。
3. 打开「开机自动打开本页」开关：以后每次登录电脑，会自动弹出这个页面。
4. 不想要了，把开关关掉即可。仅支持 macOS 电脑；手机端不支持开机自启。

原理：开关通过本地助手在 `~/Library/LaunchAgents/com.yangshuang.birthday.plist`
注册/移除一条登录自启项（只执行「打开本页 index.html」这一个动作）。

## 自定义文字

用文本编辑器打开 `index.html`：

- 顶部 `<script>` 里的 `CONFIG` 可以改名字、昵称、小狗名、城市。
- 「写给你的信」部分直接改文字即可。

## 技术说明

- 全部内容都在本地运行，不联网也能看。
- 音乐用 Web Audio 实时合成的轻快版旋律，首次点击「拆开惊喜」后播放（浏览器的自动播放策略要求一次点击）。
- 本地助手只监听 `127.0.0.1:58765`，不对外网开放。

## 线上访问

页面也可以部署到线上（GitHub Pages 等）。线上打开时「开机自动打开」开关会自动隐藏，
那是本机专属功能；换照片需要把图片放进仓库的 `photos` 目录后重新发布。
